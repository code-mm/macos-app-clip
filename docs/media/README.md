# README 展示素材

这些素材专用于仓库介绍，不包含用户的真实剪贴板记录、个人图片、账号、聊天、业务数据或桌面截图。

| 文件 | 来源 | 展示内容 |
| --- | --- | --- |
| `promo-cover.png` | ImageGen 宣传合成图 | 灰黄配色、应用图标、F1/F2 操作与演示面板 |
| `main-panel.png` | 当前 `ClipboardPanelView` 离屏渲染，2× | 四条虚构记录、搜索与粘贴入口 |
| `settings.png` | 当前 `SettingsView` 离屏渲染，2× | 快捷键与应用设置 |
| `image-preview.png` | 当前 `ImagePreviewView` 离屏渲染，2× | 应用自有图标的放大预览 |
| `text-preview.png` | 当前 `TextPreviewView` 离屏渲染，2× | 脚本内的虚构项目笔记 |

原生界面图复用真实视图与数据模型，没有另画一套界面；它们是界面渲染图，不是操作系统全屏截屏。宣传图用于介绍，不作为像素级界面或功能验收证据。

## 重新生成原生界面图

在 macOS 上、项目根目录运行：

```sh
./scripts/render-readme-assets.sh
```

脚本构建本地应用，并将虚构数据写入仅供展示的 `build/readme-render-data/`，输出上述四张原生界面图。它不调用系统剪贴板，不打开真实记录目录，不注册全局热键，也不录制桌面。图片示例仅取自仓库已有的应用图标。演示文字、记录时间固定，重新运行只替换本目录的四张原生界面图。`promo-cover.png` 不会被该脚本覆盖。
