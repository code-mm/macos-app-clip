# ClipRecord 首版验证

日期：2026-11-16。环境：Apple Silicon，本机 Xcode 27.2 / Swift 6.4.2，macOS 原生应用。

## 已通过

- Debug 编译、Release 编译和 ad-hoc 签名结构校验。
- Bundle ID：`com.codemm.cliprecord`；最低 macOS 14；菜单栏应用 `LSUIElement=true`。
- 9 项 XCTest，0 失败。完整输出：`build/test-results.txt`。
- 650 次连续写入，只保留最新 500 条、500 个载荷文件，重启重读保持一致。该测试进程 RSS 约由 79.5 MB 到 90.2 MB；其中包含 XCTest，不能当作应用驻留指标。
- 1800 × 1200 图片元信息读取、下采样最长边不超过 240 px，非法图片拒绝。
- 日志 1 MB × 4 文件轮转策略、索引损坏保护、容量限制、去重、删除与恢复。
- 实际应用窗口中观察到菜单栏面板、搜索框、手动记录按钮、文字和图片混排、快捷键设置页及日志入口。
- 真实运行日志显示文字与图片手动保存、重复记录合并、重启恢复；保存耗时约 2.7–4.9 ms（少量记录的本机样本）。
- 原生窗口截图检查并修复了初始 0 高度和记录增加后的裁切。3 条记录主窗口 472 × 580；出现提示时扩展到 656 高。
- 辅助功能权限未授予时，粘贴降级为复制并提示 ⌘V，未修改系统权限。
- 用户在本对话实测确认：双击 F1 可以正常显示／隐藏面板。该项来源为用户反馈，不是自动工具验证；未确认具体是否使用 Fn 组合。
- 按用户补充要求核查代码：热键只调用面板开关，并取消尚未完成的粘贴任务；打开面板只读取预览，未调用剪贴板写入或粘贴。粘贴由点击记录或回车显式触发。本项为代码核查，不替代权限后跨应用粘贴实测。

## 资源与实测边界

活动进程短时 RSS 样本约 110–125 MB。一次包含 UI 操作的约 90 秒运行样本：RSS 115.2 MB，区间 CPU 3.7%。这些数值受 SwiftUI 首次加载、图像解码和测试操作影响，不能宣称为空闲稳定值，更不能证明长期无泄漏。最终空闲样本在报告中单列。

最后一次 20 秒静置只读采样：RSS 前后均为 107728 KB（约 105.2 MB）；CPU 前后均 0.0%，累计 CPU 时间前后均 3.77 秒。详见 `build/resource-snapshot.json`。该样本来自本轮隔离实例，不等同于长时间稳定性保证。

窗口工具多次返回状态变化或超时，因此没有把工具按键动作视作可靠的物理 F1 验证。双击状态机的单元测试通过、系统热键成功注册；随后用户实测确认双击 F1 显示／隐藏正常。不同 Fn 模式及唤醒后热键仍未覆盖。

## 未覆盖

- 数小时／数天驻留、睡眠恢复、实际内存压力下的长期趋势。
- 多显示器、全屏空间、超小屏幕和 Intel 架构。
- Developer ID、公证、其他机器安装、开机自动启动（本版未实现开机启动）。

## 1.0.1：双击 F2 静默记录

- F1 仍只开关面板；新增独立的双击 F2 热键，直接调用保存入口，不调用显示面板、激活应用或粘贴。
- F2 复用文字／图片容量限制与去重规则。静默操作成功或失败都不改变面板提示，诊断事件带 `silent` 数值；日志不包含剪贴板正文。
- 设置显示固定的“静默记录当前剪贴板：双击 F2”，禁止将无修饰键 F2 再分配给面板开关，避免一次双击同时触发两个动作。
- 新增测试使用独立命名剪贴板验证文字和图片落盘、原剪贴板字节及 changeCount 不变、无界面回调、无提示、重复合并、空内容／非法图片静默失败，以及 F1/F2 双击互不干扰。
- 本次测试与构建证据：`build/f2-test-results.txt`、`build/f2-release-build.txt`。物理 F2 双击的最终用户验收单列，不能以代码或单元测试代替。
- 15 项测试通过（10 项核心测试、5 项静默保存测试），Release 1.0.1/code 2 构建和 ad-hoc 签名检查通过。
- 已正常重启至 1.0.1，启动记录数仍为 4；没有 F2 注册失败事件。随后用户在本对话实测确认：复制文字后双击 F2，内容已保存且没有弹出面板。该项为用户实测通过；图片静默保存由自动测试覆盖，尚未取得用户实测反馈。

## 1.0.2：图片放大预览

- 图片行／缩略图点击和选中图片后按回车都改为打开预览，不立即复制或粘贴。文字记录保持点击／回车粘贴。
- 独立预览窗口支持适合窗口、100%、放大／缩小、双向滚动和明确的“复制图片”按钮。关闭预览返回记录列表。
- 大图在后台解码，最长边不超过 4096 px、总像素不超过 800 万；原文件保持不变，复制使用原始字节。关闭后释放窗口、视图及大图引用；迟到的解码结果不进入已关闭视图。
- 20 项自动测试通过（11 核心 + 9 应用层），包括点击／回车分流、查看不写剪贴板、明确复制才写原始字节、关闭后不回填图片和像素预算。Release 1.0.2/code 3 与 ad-hoc 签名校验通过。
- 实际 UI 检查：点击 995 × 2129 图片打开预览，初始适合窗口为 31%；点 100% 后显示双向滚动条，实际截图中文字可读；缩小／适合窗口有效；关闭返回原列表。未在用户当前剪贴板上测试复制按钮，复制行为由独立命名剪贴板测试覆盖。
- 预览检查期间诊断只有 `image_preview_open`、`image_preview_close`，没有 `image_preview_copied`。升级前后均为 5 条记录、1 张图片。
- 证据：`build/preview-test-results.txt`、`build/preview-release-build.txt`、`build/preview-validation.json`。实际图片内容未复制进报告。

## 1.0.3：长文本独立窗口

- 多行、超过 80 字符或摘要已截断的文字，点击／回车先打开独立大窗口；短文本保留原有快速粘贴。图片预览、F1 显示／隐藏、F2 静默记录行为保持不变。
- 按原始纯文本完整展示，保留换行和缩进，支持选择、滚动、12–32 pt 字号和明确的“复制全文”按钮。查看不写入系统剪贴板，不执行其中的文字指令。
- 全文按需从磁盘异步读取和解码，使用原生只读 NSTextView；关闭时释放文本、视图和窗口，丢弃迟到的读取结果；图片和文本不同时保留多个预览窗口。
- 25 项测试通过（11 核心 + 14 应用层）。新增用例覆盖长／短文本分流、列表 240 字摘要之外的完整内容、原始 CRLF／缩进、查看不复制、明确复制全文、关闭释放与缺失文件。Release 1.0.3/code 4 构建和 ad-hoc 签名校验通过。
- 本机 UI 实测：用户截图中所选长文本打开后显示 6,609 字符、198 行；16→18 pt 字号调整有效，滚动条从 0 移动至约 0.469，关闭返回 5 条记录的列表。交互工具报告过外部状态变化；本轮日志出现一次 `text_preview_copied`，无法仅凭日志归因，因此不把这一轮 UI 操作作为“未改写剪贴板”的证据。查看不写入、明确复制才写入由独立命名剪贴板测试验证。
- 证据：`build/text-preview-test-results.txt`、`build/text-preview-release-build.txt`、`build/text-preview-validation.json`。预览中的用户文字及运行截图不复制进报告。

## 1.0.4：顶部粘贴记录区

- 参考用户截图中的粘贴区域，将旧的当前剪贴板摘要替换为虚线边框收录区；沿用灰黄系列，提供“选择图片”和“粘贴记录”按钮、文字／图片标记、⌘V 与 F2 提示。
- 收录区支持直接粘贴和拖入文字／单张图片；面板非编辑区域按 ⌘V 保存，搜索框中仍正常粘贴搜索词。系统图片选择器仅选择图片。
- 支持 PNG、JPEG、TIFF、HEIC、GIF、BMP 文件。PNG/TIFF 保留字节，其余格式转静态 PNG，复用既有像素／大小限制与去重。通用文件、多文件一次拖入被明确拒绝。
- 取消旧摘要后，打开面板不再读取剪贴板；只有明确粘贴、选择／拖入或 F2 时收录。
- 30 项测试通过（11 核心 + 19 应用层）；新增测试覆盖文件 URL 粘贴、JPEG 转换、拒绝不支持文件／多文件、拖入文字入口与容量限制。
- 本机实测新粘贴区布局、系统图片选择器打开／取消、面板 ⌘V 保存成功、成功提示时高度与列表滚动。新增记录在 UI 中可见。由于会话存在用户外部剪贴板变动，不将其正文归因于受控测试。真实拖拽手势与选图后确认仍未完成 UI 验收，底层导入测试通过。
- 证据：`build/capture-test-results.txt`、`build/capture-release-build.txt`、`build/capture-validation.json`。历史图片和长文本预览、F1/F2 继续保留。

## 1.0.5：F2 记录结果反馈

- F2 静默记录成功提交后才触发菜单栏勾选闪烁和系统 Tink 提示音，约 0.85 秒后恢复原图标。重复内容更新成功同样触发一次反馈。普通粘贴按钮保存不触发 F2 提示音。
- 空内容、非法图片、写入失败或保存忙碌时使用警示图标与 Basso 提示音，不误报成功；全程不打开面板、不激活其他窗口、不改写当前剪贴板。
- 反馈只在操作后运行短任务；重复触发取消上一次闪烁，结束、睡眠或退出恢复原图标。诊断记录 `record_feedback` 中的成功标志及声音启动返回值，不记录剪贴板正文。声音启动成功不等于用户听见，仍受系统静音与输出设备影响。
- 35 项测试通过（11 核心 + 24 应用层），新增验证成功提交后反馈、重复保存、失败不报成功、普通按钮无提示音、闪烁结束／重入／取消后恢复。测试使用独立剪贴板与注入声音播放器，不播放测试音。
- Release 1.0.5/code 6 构建、签名检查通过，已重启，原有 7 条记录保留。用户随后在本对话实测确认：双击 F2 后图标闪烁和提示音都正常，面板没有弹出。成功反馈的用户感知验收通过；失败反馈仍以自动测试结果为依据。
- 证据：`build/feedback-test-results.txt`、`build/feedback-release-build.txt`、`build/feedback-validation.json`。
