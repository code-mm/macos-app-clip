# 剪贴板 v1.0.6

原生 macOS 菜单栏剪贴板记录器，支持手动保存文字与图片。

## 下载与安装

- 系统：macOS 14 或更新版本。
- 芯片：Apple Silicon（M 系列，arm64）；不支持 Intel Mac。
- 推荐下载 `ClipRecord-1.0.6-macOS-arm64.dmg`，打开后把 `ClipRecord.app` 拖到 `Applications`，再从应用程序中启动。
- 也可下载 ZIP，解压后将应用放入“应用程序”。
- 应用启动后常驻菜单栏，不显示 Dock 图标。
- 升级时先退出旧版本，再替换应用；个人记录存储在用户资料库中，不随应用替换而删除。

当前仓库为私有，下载需要登录拥有该仓库访问权限的 GitHub 账号。

## 功能

- 双击 F1 显示／隐藏面板；双击 F2 静默保存剪贴板，不弹出面板。
- F2 保存成功后，菜单栏绿色闪烁并播放 Ping 提示音。
- 搜索记录，支持粘贴、拖入文字或图片，以及选择图片。
- 图片独立放大预览；长文本完整阅读、调整字号和复制全文。
- 本地保存，历史容量限制与图片按需加载，提供运行诊断日志。

部分键盘需要配合 Fn 使用功能键；也可在设置中修改面板快捷键。

## 签名与首次打开

应用已使用 Developer ID 签名并启用 Hardened Runtime，**尚未经过 Apple 公证**。首次下载后可能出现 macOS 安全拦截，签名有效不代表已公证。

确认安装包来自本仓库、校验值一致后，可参考 [Apple 官方打开说明](https://support.apple.com/zh-cn/102445)，在“系统设置 → 隐私与安全性”处理。无需关闭 Gatekeeper，也不需要运行移除隔离属性的命令。

快捷粘贴到其他应用需要用户自主授予辅助功能权限；未授权时仍可复制后手动粘贴。
