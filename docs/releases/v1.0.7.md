# 剪贴板 v1.0.7

## 本次更新

- 双击 F2 保存成功的提示音替换为新的确认音效，约 1.3 秒。
- 音效随应用内置，按需加载并复用，不依赖外部文件。
- 保留绿色闪烁、F2 静默记录、F1 显示／隐藏面板和原有失败提示音。
- 用户已实测确认新音效正常，36 项自动测试通过。

## 下载与安装

- 支持 **macOS 14 及以上、Apple Silicon（M 系列，arm64）**；不支持 Intel Mac。
- 推荐下载 `ClipRecord-1.0.7-macOS-arm64.dmg`，打开后将 `ClipRecord.app` 拖入 `Applications`，再从应用程序启动。
- 也提供 ZIP：解压后把应用放入“应用程序”。
- 更新前先退出旧版本，再替换应用。个人记录保存在用户资料库中，替换应用不会删除记录。
- 应用常驻菜单栏，不显示 Dock 图标。部分键盘需配合 Fn 使用 F1/F2。
- 仓库和 Release 已公开，无需登录 GitHub 即可下载。

## 签名与校验

应用使用 Developer ID 签名并启用 Hardened Runtime，**尚未经过 Apple 公证**。首次打开可能被 macOS 拦截；确认来源及校验值后，可参考 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。无需关闭 Gatekeeper 或执行移除隔离属性的命令。

版本号为 1.0.7，内部构建号为 8。附带 `SHA256SUMS.txt`：DMG、ZIP 和该清单在同一目录时，可运行 `shasum -a 256 -c SHA256SUMS.txt` 核对。

下载包不包含个人剪贴板记录、测试数据、运行日志或调试符号。跨机器首次安装、辅助功能授权后的跨应用粘贴与长期驻留仍未完整验证。
