## 共同视觉规则

| 用途 | 颜色 |
| --- | --- |
| 页面与面板底色 | `#F5F6F8` |
| 内容面 | `#FFFFFF` |
| 主要文字 | `#212A36` |
| 主按钮与图标轮廓 | `#333E49` |
| 次要文字 | `#626F7F` |
| 暖黄强调 | `#FFCE54` |
| 选中背景 | `#FFF7DF` |
| 分隔线 | `#E3E7EC` |

界面采用清楚的层次、白色分组、克制圆角、轻分隔线和深灰主操作按钮。暖黄用于应用标记和选中反馈。转为 macOS 紧凑面板，不照搬手机页面字号和导航结构。

新图标以暖黄剪贴板、两条文字线和图片山形组成，粗深灰轮廓与现有系列保持一致；避免使用 LanClip 的链环，区分本地记录与局域网共享。

## 交互意图

- 点击菜单栏图标或自定义快捷键显示／隐藏面板。
- 打开时预览当前剪贴板；点击“记录当前剪贴板”才保存，不自动记录。
- 第一阶段仅支持文字和图片。
- 历史项支持快速粘贴；键盘上下选择、回车粘贴、Esc 隐藏。
- 设置中的 `⌥ Space` 仅是初稿默认值示例，用户可重新录制组合键。
- 原生粘贴权限、窗口焦点恢复、快捷键冲突和真实剪贴板格式处理，均留待应用实现与验证。

## 本轮生成提示摘要

### 图标

参考四个现有应用图标，生成同系列的单个本地剪贴板应用前景：暖黄 `#FFCE54` 主体，粗深灰 `#333E49` 圆润轮廓；夹板内两条文字线和简洁山峰／太阳图片标记；透明方形画布，居中留白；不用链环、音符、下载箭头、文字、装饰徽章或立体阴影。

### 主面板

附上第 1 版结构稿、快享盒／个人音乐／LanClip 界面及新图标。保留菜单栏右上角锚定浮层，顶部图标／标题／快捷键／设置、搜索框、当前剪贴板预览、手动保存按钮、文字图片历史列表和键盘提示。转换为浅灰底、白色内容面、深灰主按钮、暖黄选中态。准确的简体中文标签，原生 Mac 字体与紧凑尺寸。桌面同时展示带白色底板的新图标。无自动记录、账号、云服务或额外功能。

### 快捷键设置

附上新主面板与图标，生成同一设计的设置页；显示／隐藏快捷键录制框、恢复默认、Esc 隐藏提示、手动记录说明及完成按钮。沿用灰黄颜色和原生 Mac 窗口，简洁的中文文案；不增加无关设置。
